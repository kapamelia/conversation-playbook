# S-16 · 判断依据：一个说法可信到什么程度

## 这一页解决什么

前面每一页都在告诉你「怎么做」。这一页回答一个更前面的问题：**凭什么信。**

> **本页是一把尺子，不是一个结论。** 尺子本身也有它量不到的东西——见最后一节。

---

## 一、为什么要单独做一页

因为**大多数错的决定不是被错误信息骗的，是被说得太顺的说法骗的。**

「这样做 → 他就会那样」——这句话的问题不在于内容假，而在于**中间的因果链被省略了**。省略掉的那一段里，通常包含：样本有多大、有没有对照、成功的人里有多少本来就会成功。

**要看穿它，需要机械执行几个动作，不能靠阅读时的直觉。**

---

## 二、条目

#### S-16-01 · 先问「这句话是谁说的」
- **四个动作**：
  - **① 能不能追到具体位置？** 这句话出自哪本书、哪一页、哪一篇？**追不到，就先按「无从核实」处理。**
  - **② 说这句话的人是谁？** 是研究者、是执业者、是经验分享者，还是转述者？
  - **③ 转述到了第几手？** 如果一个人引用另一个人引用一本书——**引用要指向原书，中间那层不算依据。**
  - **④ 他有没有越用？** ⚠️ **最常见的越界是：拿一个「怎么做」的技巧，去支撑一个「为什么」的断言。** 「他教我这么说」不等于「这么说真的有用」。
- **机制**：来源可核不等于正确，但**来源不可核意味着无法被检验**。这一条的作用是把说法分成「可检验」和「不可检验」两堆，而不是分成「对」「错」两堆。
- **失效信号**：你开始因为作者有名就跳过这一步——**有名只提高可核对性，不自动等于正确。**

#### S-16-02 · 百分比怎么读（五类处置）

| 你看到的句式 | 该怎么处理 |
|---|---|
| 「100% 成功」「只要…就能…」 | **绝对化宣称。** 任何单一心理路径对行为的解释力都是有限的（见下），这类句式的字面含义**必然超出可能范围** |
| 「71% 的人」「76.3%」且没有抽样说明 | **无从核实。** 不用管它对不对，它无法被检验 |
| 执业者说「我见过的案子里大约一半」 | **既不要当成统计，也不要当成胡说。** 正确写法是「**执业观察**」——它是有价值的经验，但不是数据 |
| 「相关系数是 .7」被说成「导致」 | → 见 S-16-03 |
| 「28 天一个周期」「21 天养成习惯」 | 出处不明的流行说法。**默认按无依据处理** |

**两条校准用的参照**（用来判断一个数字有没有超出合理范围）：

- **任何单一心理路径，对行为的解释力大致在 30% 上下封顶。** 具体说，一个被反复检验的经典模型（态度 + 社会规范 + 感知到的行为控制 → 行为意向）在十项研究的汇总中，平均多重相关约为 **.51**，范围 **.20–.78**。
- **重点不在 .51，在 .20 那个下限。** 同一个模型用在不同行为上，**下限那头只能解释约 4–7% 的方差**——也就是说，还有九成以上的变异来自模型之外。

> **由此得到一条可以直接用的判据：凡是宣称某个方法能决定性地解决某类关系问题的，都可以先假定它夸大了。** 不是因为那个方法没用，而是因为**单一路径在结构上不可能有那个分量。**

#### S-16-03 · 四类最常见的推理断裂

| 错误 | 长什么样 | 怎么识破 |
|---|---|---|
| **相关当因果** | 「用了这个方法之后他们成了」 | **问一句：不用这个方法、或者用别的，会不会也成？** 没有对照就没有结论 |
| **个案当规律** | 一整套案例集，全是成功案例 | **问一句：失败的那些去哪了？** 只收录成功结果的合集，信息量远低于它的厚度 |
| **计划当结果** | 引用一份研究，说它证明了某件事 | **问一句：这是研究方案还是研究结果？** 方案说明「打算怎么做」，不出结论 |
| **术语当理论** | 用一个自造词解释一件事 | **问一句：这个词除了这件事，还能解释别的吗？** 只能解释它自己，就说明它不是一个解释项 |

> **第三类最隐蔽**：一份「研究计划」读起来和研究报告几乎一样，有方法、有假设、有参考文献——**唯独没有结果**。看到「本研究拟…」，就要停下来。

#### S-16-04 · 反向检查：你自己有没有在滥用这套判据
- **适用**：你开始用上面几条去否定一切
- **三条反向红旗**：
  - **「没有出处，所以是错的」** —— 来源不明只说明**无法检验**，不等于结论错误。生活里大量正确的经验判断是没有文献的。
  - **「不是研究结论，所以不重要」** —— 执业者的经验、你自己的观察，都是有效的信息，只是**不能冒充数据**。
  - **「有反例，所以不成立」** —— 一个说法被一个反例推翻，只发生在它宣称自己是普遍规律的时候。**大多数关系里的建议本来就是概率性的。**
- **机制**：这套判据的用途是**排序**（哪些更值得信），不是**裁决**（哪些不许信）。用成后者，它会优先筛掉有出处的、放过没出处但正确的直觉——**方向正好相反。**
- **失效信号**：你用这套判据之后，发现自己什么都不敢信了。**这说明你不是在用它筛信息，是在用它防御。**

#### S-16-05 · 这套判据**不适用于**什么

有五类内容，**不要**拿「相关性」「可证伪性」去审查它们：

| 不适用 | 为什么 |
|---|---|
| **主观体验** | 「我当时很心动」「被拒绝之后很难受」——**这些不是待验证的主张，是在陈述感受** |
| **价值判断** | 「应不应该在这个阶段确认关系」没有事实答案 |
| **文化差异内的习俗** | 不同家庭、地区对「什么时候见家长」的预期不同，不存在统一标准 |
| **对方没说出口的意图** | **你没法用证据论证一个人在没说话时的想法。** 这一条最重要——本手册里所有「他这样是不是不爱你」的问题，都不属于这一页 |
| **你自己的直觉** | 直觉不是证据，但它**是一个信号**：它通常来自你还没整理出来的观察 |

> **「他到底什么意思」这个问题，本页回答不了，也不该用本页回答。** 它属于沟通问题——**去问**。

## 三、这一页自己的局限

| 局限 | 说明 |
|---|---|
| **尺子比被测物短** | 上面这些判据全部来自学术心理学，而学术心理学本身也不是全能的——它是**非临床的、样本偏向特定人群的、教材化的** |
| **无法检验体验** | 见 S-16-05 |
| **有「用工具替代判断」的风险** | 机械执行判据会让人觉得只要流程对了结论就对了。**本页是过滤器，不是裁决者** |
| **多数判据本身还有待核实** | 本页引用的若干条来源尚未逐件复核，**上面给出的数字应按「目前最好的估计」理解，不是定论** |

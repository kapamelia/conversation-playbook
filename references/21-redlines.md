# 红线清单（**无条件优先**）

> **优先级声明**：本页是本手册的**硬约束页**。其余任何内容与本页冲突时，**以本页为准**。
> 本页不是参考读物，是判断依据。**与它冲突时，本手册其余任何内容作废。**

---

## 零、总则

本手册其余全部内容都在回答「怎么说更好」。本页回答的是「什么不做」。

**这两类问题的答案不能互相交换。** 「这样说效果更好」永远不能推翻「这件事不做」。

---

## 一、绝对不做

以下不是「有风险」，是**不做**。

| 类别 | 具体行为 |
|---|---|
| **欺骗** | 伪造身份、经历、收入、婚姻或关系状态；假装偶遇；用未说明的规则或借口取得身体接触；编造追求者制造竞争 |
| **贬低** | 以否定对方的外形、能力、朋友、家庭来降低其自我评价；给对方贴贬损性的标签 |
| **要挟** | 以自伤、分手、公开隐私、切断经济支持来迫使对方改变决定；以「你答应过」来否定对方改变主意的权利 |
| **越界接触** | 未获明确同意的身体接触；把人带到无法自由离开的地方；在对方判断力受损时推进 |
| **监控** | 未经同意查看手机、行踪、社交账号；持续追踪对方动向；用他人代为打听 |
| **剥夺自主** | 隔离对方的社交关系；要求对方删除联系人；用道德审判缩小其世界；以「关心」为名限制其选择 |
| **脆弱时刻推进** | 在对方醉酒、生病、情绪崩溃、刚经历重大变故、经济困难时推进关系 |
| **持续纠缠** | 在被明确拒绝后继续联系、换号联系、通过第三方传达、在对方常出现处「偶遇」 |

> **法律边界提示**：上表中部分行为在中国大陆可能构成**骚扰、侵犯隐私、非法侵入、强制猥亵**等，需要承担行政或刑事责任。
> 以条件交换亲密关系、偷拍、跟踪同样可能违法。**动机不能改变行为的性质。**

> **本页与 `18-tactics-library.md` 的关系**：手法库里 E 组的五条（把亲密当交易、以欺诈促成接触、利用脆弱期、把身体接触当情绪工具、预设流程链）**没有「做法」栏**，原因就在这一节——它们的效果与伤害是同一个东西，不存在一个「用得恰当」的版本。

## 二、不属于本手册推荐范围的做法

以下不是禁令，但它们**不属于本手册推荐的范围**——因为它们的作用机制依赖对方的不知情：

| 做法 | 问题 |
|---|---|
| 假装忙碌 / 刻意延迟回复 | 用不确定性制造焦虑 |
| 忽冷忽热 | 不可预测会损害安全感；短期可能有回应，长期损耗信任 |
| 留白吊胃口超过一天一次 | 从「有趣」变成「消耗」 |
| 设计情境「测试」对方反应 | 解释权在你手里（怎么回都能读成想要的结果），且一旦被察觉代价很大 |
| 把「冷淡」理解为需要攻克的关卡 | 这是把不感兴趣重解释为等待 |
| 用性格类型、星座、MBTI 决定怎么对待一个人 | **群体标签解释不了一个具体的人** |
| 把人按「类型」归类后套用固定策略 | 以标签替代认识 |
| 用「付出」作为索取凭据 | 付出是自愿的，不能兑换成对方的义务 |
| 在公开平台发暗示性内容等特定的人来接 | 把沟通变成让人猜 |
| 把每一次分歧记下来当以后翻的「证据」 | 分歧再也无法被单次解决 |
| 对任何一条建议问「有没有效」而不问「代价是什么」 | 只问效果会系统性地筛掉边界 |

**这些做法在 `18-tactics-library.md` 里都能找到对应的机制说明与代价。** 想了解它们为什么会被使用，去那一页；**想确认要不要用，答案在这一页。**

## 三、停止使用本手册的情形（**无条件优先**）

### 3.1 三层识别判据

⚠️ **使用前提：这三层只用于「识别与转介」，不得用于评估他人并据此调整策略。**

| 层级 | 触发信号 | 处置 |
|---|---|---|
| **🔴 立即（不追问、不评价、不判断严重性）** | 明确的自伤 / 自杀意念或计划；正在发生的暴力；被限制人身自由 | → 见 §3.2，**同时停止使用本手册全部技巧内容** |
| **🟠 高度关注** | 持续的绝望感、无价值感、「我消失了会更好」式表述；自我隔离突然加重；被反复贬低后开始认同贬低（「除了他没人要我」） | → 提示求助，**不建议「靠自己调整」**；同时按 `17 §五` 检查退出能力 |
| **🟡 需要提示** | 关系中出现持续的控制、隔离、经济依赖；反复出现的自伤玩笑式表达 | → 补一条关系风险提示，并观察是否升级为 🟠 |

> **三层之间不是程度差别，是处置差别。** 🔴 层不做任何评估——**任何「看起来不严重」的判断都不成立。**

### 3.2 停止清单

出现以下任何一种情况，**本手册的全部技巧内容（开场、话题、邀约、节奏、信号判读、文字策略、手法库）立即停止使用**。

| 情形 | 该做的是 |
|---|---|
| **自伤 / 自杀念头或计划**（对方或你自己） | **不评估、不追问、不判断严重性。** 立即寻求专业帮助（见下） |
| **关系中存在暴力**（身体 / 精神 / 经济） | 不将此视为「沟通问题」。优先确保人身安全，联系当地相关求助渠道 |
| **涉及未成年人** | 无论对方是否表示同意，**一律停止**。这是法律问题，不是技巧问题 |
| **涉及怀孕、性传播感染、药物使用** | 不依赖任何关系类建议。走正规医疗渠道 |
| **涉及隐私、胁迫、可能的违法行为** | 咨询专业法律意见 |

**可见的求助路径**（⚠️ 以当地实际公布为准）：

| 情形 | 路径 |
|---|---|
| **紧急 / 有立即危险** | **拨打 120（急救）或 110（报警）**，或直接前往就近医院急诊 |
| **心理援助** | **12356**（全国统一心理援助热线）——号码以当地卫生健康部门实际公布为准 |
| **其他** | 各地精神卫生中心 / 三甲医院**精神科或心理科**门诊 |

> ⚠️ **本页只给路径，不给具体机构名单**——这类信息时效性强、地区差异大，写死会随城市与年份失效。

### 3.3 三条纪律

| # | 纪律 |
|---|---|
| **1** | **不做评估**——本手册不是危机评估工具，任何「看起来不严重」的判断都不成立 |
| **2** | **不替代专业求助**——任何时候，本手册都不能是唯一的支持来源 |
| **3** | **危机情境禁用技巧**——所有话术、节奏、信号判读、手法库的内容，在危机中全部停止 |

### 3.4 一条给使用者的话

如果你正在经历上面任意一种情况：**这不需要被处理得漂亮，只需要被处理。**

不需要先想清楚怎么说、不需要找到合适的措辞、不需要担心「是不是小题大做」。**直接找人、直接打电话、直接去医院，都是完整的答案。**

## 四、一个底线问题

> ### **我是为了让对方更愿意靠近我，还是为了让对方更难离开我？**

- 前者是**吸引**——它依赖你本身值得接近
- 后者是**控制**——它依赖对方失去选择

两者在手法上常常只差一步：同样是「不提这件事」，可以是体贴，也可以是隐瞒；同样是「留一点空白」，可以是分寸，也可以是吊着。

**这一步之差，是本手册全部边界所在，也是本页存在的唯一理由。**

---

## 五、一条必须承认的结构性事实

本手册收录的内容，绝大多数都在教人**「更有效地影响对方」**。而本页处理的风险——自伤、暴力、被剥夺的自主——它们的共同上游，是**一个人被拿走了做决定的空间**。

**这两件事不是无关的，它们是同一条链的两端。**

也就是说：**教人影响对方的技法，与识别一个人被剥夺自主的信号，用的是同一套知识。** 区别只在于你站在哪一头。

本页的位置是明确的——**它是这条链上唯一一个不提问、不权衡、不接受例外的节点。** 前面二十页都可以讨论「什么情况下用什么」，**本页不讨论。**

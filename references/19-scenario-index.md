## 二、反向索引（**什么情况下不要用这些内容**）

| 情形 | 处置 |
|---|---|
| 对方已明确拒绝 | 只读 `08 §三`，**其余章节全部不适用** |
| 存在职权关系（上下级 / 师生 / 医患） | `13 §五`，**所有推进类内容不适用** |
| 对方未成年 | **停止**（`21 §三`） |
| 对方处于脆弱处境（重大变故 / 经济依赖 / 情绪低谷） | `13 §五`，不推进 |
| 对方已有伴侣且未明示关系状态 | 停止——你参与的是隐瞒 |
| 出现自伤、暴力、医疗或法律风险 | **`21 §三`，停止使用全部技巧内容** |
| 你的目的是「让对方产生某种情绪以便控制」 | 见 `18` 全页的「代价」栏——**这一栏就是答案** |
| 你只打算接受一个答案 | `08 §五`——那不是询问，是施压 |
| 你正在反复搜索「怎么让他回我」 | `08 §四`——先停止搜索 |
| 你在用本手册解释他为什么还不回我 | `16 §二 S-16-05`——**这个问题本手册回答不了，去问** |

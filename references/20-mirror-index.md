# 跨位置镜像对照表

## 这一页做什么

同一批术语、同一套动作，**在推进方和被推进方那里，处方经常是相反的**。

这一页把那些**相反之处**集中列出来。目的只有一个：

> **读懂一边，才能认出另一边。** 你能被用来对待的方式，取决于你是否知道那套方式长什么样。

**本页只并置，不调和。** 每一组的两侧都成立——但成立的前提不同，而**两侧的资料都没有把前提写出来**。

---

## 一、四组「同词反义」

### 1. 需要

| | 推进方 | 守方 |
|---|---|---|
| **主张** | **藏起来。** 暴露需要是三大误区之一；有所谓「隐藏需要的三条铁律」 | **说出来。** 「你不敢期待，就不该期待」；反对单向依赖，但赞同表达 |
| **为什么** | 需要是**怕被看穿的弱点** | 需要是**怕被白占的投入** |
| **共同缺口** | 一个要藏、一个要说，**但都没写出「什么前提下用哪一套」** | |

> ⚠️ **两者都不是「诚实表达」路线。** 藏是一种策略，限量说也是一种策略。真正被漏掉的第三种做法是：**直接说清楚你需要什么，并且不把它当成筹码。**

### 2. 边界 / 原则

| | 推进方 | 守方 |
|---|---|---|
| **定性** | **要主动建立的武器**——「一个人妥协的难易程度就是原则」 | 前期同向（言行一致 = 强原则）；**后期被当作心理健康指标**——「不敢立边界」是低自尊的症状 |
| **用途** | 进攻：不被对方的原则带走 | 防御：不被自己的低自尊拖走 |
| **共同缺口** | 同一根因（怕被带走），两种命名 | |

> ⚠️ **同一术语，一侧是武器，一侧是体检指标。** 差异不在事实层，在**立场层**。

### 3. 在别处有选择

| | 推进方 | 守方 |
|---|---|---|
| **定性** | **失败特征**——「没有别的选择」是备胎特征之首 | **风险控制**——「不要把所有鸡蛋放在一个篮子里」 |
| **用语** | 备胎（贬义） | 备选项（中性偏褒） |
| **共同缺口** | 两侧**都没有区分**「未确立关系前的正常多线接触」（可接受）与「已确立关系后的隐瞒式保留」（不可接受） | |

> ⚠️ **本手册对这一条的处理**：措辞切割不改变行为本身。**上面那个区分是本手册补的，两侧资料都没有做。**

### 4. 出题考验

| | 推进方 | 守方 |
|---|---|---|
| **位置** | **被动接招方**——所有比较级问题都要接 | **主动出题方**——「这是天生就有的筛选机制」 |
| **态度** | 视其为必然存在的机制，需要应对 | 视其为必然存在的机制，可以使用 |
| **共同缺口** | **两侧都预设了一个对抗性的关系模型** | |

> ⚠️ 两侧都把它当成关系里必然存在的东西。**这个共识本身就是值得怀疑的**——它可能只是两侧资料共同的立场，而不是关系的性质。

## 二、方向相同但位置相反的三组

这三组不是冲突，是**同一动作的可互换措辞**——**换一个位置，同一句话就是威胁，也是自保。**

| 动作 | 推进方的用法 | 守方的用法 |
|---|---|---|
| **主动离场** | 在最热的时候收线 | 「在最开心的时候离开，印象最深」 |
| **让他做选择** | 邀约时给两个选项 | 日常里问「你觉得我穿这件还是那件」 |
| **保留对方的拒绝自由** | 化解邀约顾虑 | 「你给他拒绝的空间，他反而很难拒绝」 |

**这三组的价值在于**：**它们本身是中性的技术**。它们是否成为操控，取决于**目的是让对方更愿意靠近，还是让对方更难离开**——这一条见 `21-redlines.md` §四。

## 三、四处已确认的未解争议（**不调和**）

| # | 争议 | 两侧说法 | 本手册的处理 |
|---|---|---|---|
| **1** | **表白/确认关系的时机** | 五方口径互不相同，甚至**同一份资料内部前后矛盾** | 保留为分歧。操作建议见 `S-07-03`：**先问自己三个问题，再决定要不要说** |
| **2** | **陪伴到底是不是吸引力** | 一侧把它列为被忽视的吸引力之一（「多找她聊天，制造一个习惯」）；同一侧另一处反驳：「陪伴是最长情的告白，这句话是说给已经在一起的人听的」 | 两者成立的前提不同（一个有基础好感，一个没有）。**操作含义：做陪伴之前，先确认吸引是否已经存在**——否则陪伴就是成为容器的入场券 |
| **3** | **吵架该收紧还是敞开** | 一侧是行为主义路线（用后果调节行为，冷处理是一种惩罚）；另一侧是依恋路线（暴露脆弱、创造联结） | 保留为分歧。**先判断对方此刻是「在防御」还是「在试探」**，再选路径（`S-09-05`） |
| **4** | **爱是感觉还是选择** | 两侧资料都以「感觉 / 情绪 / 触发点」为操作核心；另一侧的立场是「爱是一种抉择」（意志层） | 保留为分歧。**这两条在实操上会导致完全不同的长期策略** |

## 四、两侧共享的三个缺陷（这一节是对全部来源的总评）

| 缺陷 | 表现 |
|---|---|
| **博弈叙事** | 两侧都把关系理解为零和博弈，区别只在站位。一侧说「两个人之间就是一场战争」，另一侧说「本质都是博弈，各取所需」 |
| **幸存者偏差** | 一侧的案例集**全部是成功案例、无任何后续**；另一侧**全系列无失败案例**。两侧都只收录了赢了的人 |
| **方法挂账** | 两侧都大量点名不给方法：「九条禁错」未复原；「潜移默化四步」「铺垫法」「第 5–10 步」讲师明说「以后再讲」 |

**还有两处只有一侧成立、但严重程度更高的问题：**

- **安全红线缺口**：一侧把「好想自杀」与「跳伞」并列当普通情绪示例，**全程无危机识别、无求助渠道、无免责声明**；另一侧讲「未婚先孕」时**只讲社交施压与经济补偿，医疗风险、心理创伤、法律责任全部缺失**。→ 本手册据此在 `21-redlines.md` 建立了独立协议。
- **机制出处极低**：其中一侧的资料列出的机制项里，绝大多数没有出处；且被误以为引用的两个心理学术语，在该资料中**全文 0 次出现**。

## 五、这一页说明的一件更重要的事

把两侧并排放在一起，能看到一个单看任一侧都看不到的东西：

> **这套东西不是「某一方追另一方的方法」，而是一套「位置的操作手册」。**
> 谁更投入、谁更怕失去、谁先把底牌亮出来——技法就服务于站在下风的那个人，**与性别无关**。
> 两侧给出的所有工具，本质上都在做同一件事：**改变「谁更需要谁」这个比值。**

这也解释了为什么会出现「同词反义」——**同一个词，在推进方嘴里是攻击手段，在被推进方嘴里是防御工事。**

而两侧资料共同缺的东西，恰恰是这套体系之外的部分：

> **21 份资料里，没有任何一份讨论过「双方都已投入、且都不打算改变这个比值」之后该怎么相处。**

**本手册如实记录这一空缺。** 这不是技巧问题——**当双方都停止计算时，关系才第一次不是博弈，而这一步不取决于方法。**

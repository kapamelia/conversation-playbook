# Conversation Playbook · 会话与关系手册

**大多数话术教你「怎么说得更好」。这份手册先告诉你——「这句话该不该发」。**

从第一句话，到该不该继续。一份按处境取用的沟通判断手册。

## 这是什么

一句话：**它是一个会先质疑你问题的沟通手册。**

你问「这句话怎么改」，它可能回答你「这句话不该发」，或者「你们的关系还没走到这一步」。

它覆盖从**开口破冰**、**暧昧升级**、**邀约见面**，一路到**长期经营**、**冲突修复**，以及 **「这段关系要不要继续」** 的完整跨度——并且在你取用建议前，先告诉你**这个处境下哪些内容不适用**。

> 它不是让你更会"说话"，而是让你更少**在错的时间、对错的人、说错的话**。

---

## 为什么它和别的不一样

市面上不缺"高情商话术"，缺的是**判断力**。以下是这份手册刻意的不同：

### 1. 【判断】永远排在【话术】前面

```text
【判断】         这个处境下真正的问题是什么（常常不是你以为的那个）
【可以这么说】    1–3 条可直接发出去的原句，标注各自适用条件
【对方这样回，你这样做】 分两三种回应分支给下一步
【不要这样做】    3–5 条，说清为什么
【风险提示】      涉及边界、安全、法律时必给
```

**多数时候，你真正需要的不是一句更好的措辞，而是一个更清醒的判断。**

### 2. 「可退出性」高于一切

- 对方的沉默、含糊、转移话题，都是**有效回答**，不是需要破解的谜
- 「不」不需要理由；「再想想」「下次吧」按「不」处理
- 这条原则**高于手册其余全部内容**

### 3. 它敢承认自己不知道

当信号分不出「对方在犹豫」还是「对方没兴趣」时，它**不编一个方法出来**——只给你一条能用的判据：

> **看趋势，不看单点。三个月没有变化，就是没有变化。**

### 4. 操控手法一面写代价，一面标红线

对涉及操控的内容，它做成**两个页面**：一页只做**识别**，一页写清**机制、代价、失效信号**。而 `红线页` **无条件优先**——与它冲突时，手册其余内容全部作废。

## 核心亮点

- **92 条编号条目**，每条都带 **适用 / 机制 / 失效信号 / 禁用场景**——**「失效信号」写的是"什么时候该停"**
- **近 90 条可直接发出去的例句**，不是空泛原则，是能复制粘贴的原句
- **18 个内容类别**，涵盖从展示面到自我修复的完整链路
- **场景速查索引（正向 + 反向）**：不仅告诉你"该读什么"，也告诉你"别看什么"
- **两侧镜像对照**：同一件事，「被追的一方」和「追的一方」的处方是相反的——读懂一边，才能认出另一边
- **零依赖本地检索**：一个 Python 脚本跑通全部 92 条，**不联网、不读写其他路径**
- **承认空白与不确定性**：标注哪些是归纳、哪些有口径分歧，并专门教你怎么判断"一个说法可信到什么程度"

## 适合谁

**正在经历具体处境的普通人：**

- 「第一句该说什么」「聊不下去怎么办」
- 「他到底对我有没有意思」「能不能约出来」
- 「被已读不回怎么办」「吵架了怎么修复」
- 「这段关系值不值得继续」「我是不是越界了」
- 「对方是不是在操控我」「这个说法可信吗」

**以及两类容易被忽略的人：**

- **我是被追的一方**——手册有独立的守方视角页（`15`）
- **AI 助手开发者**——把判断框架、边界规则、输出格式直接接入你的 Agent

## 快速上手

### 安装

```bash
git clone <your-repo-url> ~/.workbuddy/skills/conversation-playbook
```

将本项目放入你的 skills 目录即可。作为 CodeBuddy / WorkBuddy skill 使用时，加载 `SKILL.md` 后即可按处境调用。

### 使用：三步工作流

1. **先确认三件事**（不能跳）：关系阶段 · 当前状态 · 媒介
2. **只加载需要的那一个参考页**（不要一次读多个）
3. **按固定五段式输出**（顺序不变）

### 检索脚本（零依赖、离线可用）

```bash
python scripts/lookup.py --cats            # 类别总表（先看这个）
python scripts/lookup.py --list            # 全部条目（92 条）
python scripts/lookup.py --cat 09          # 按类别列出（09 = 冲突与修复）
python scripts/lookup.py 已读不回           # 按关键词检索
python scripts/lookup.py --stage 冷淡       # 按处境检索
python scripts/lookup.py --scenario        # 场景速查（正向 + 反向）
python scripts/lookup.py --files           # 以文件为单位列出标题
```

> 脚本路径**相对自身解析**，因此可以在任意目录下调用。

## 设计哲学

四条不可动摇的纪律：

| # | 纪律 |
|---|---|
| **1** | **可退出性优先。** 对方的沉默、含糊、转移话题都是有效回答。这一条高于其余全部内容。 |
| **2** | **不做评估，不替代专业帮助，危机中禁用技巧。** |
| **3** | **不合并两种视角。** 「被追的一方怎么做」与「追的一方怎么做」是两份不同的内容，不揉成一句话。 |
| **4** | **不把群体标签当个体说明。** 不采用「男性思维 / 女性思维」「星座 / MBTI 决定对方喜欢什么」这类断言。 |

还有一条贯穿全书的提醒：

> **「我做得更好 → 对方就会回应」是因果倒置。**

## 项目愿景

我们相信：**关于关系的绝大多数痛苦，不来自"话说得不够好"，而来自"看错了处境"。**

所以这份手册的目标，不是把你训练成一个话术高手，而是让你在面对一段关系时——

- 看得清**信号**，而不是把不感兴趣读成"她在考验我"
- 守得住**边界**，既不为难别人，也不委屈自己
- 认得清**自己**，知道什么时候该用力，什么时候该放手

如果它能帮你**少发一条不该发的消息、早一点看清一段消耗你的关系**，它就已经值回票价。

> 我们不产出"攻略"。我们产出的是——**让你不需要攻略也能好好相处的能力。**
